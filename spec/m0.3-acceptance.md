Final outputs and source hashes are in spec/evidence/m0-release-local.json; exact-head CI is recorded in PR #771.

Candidate installation executes no plugin code. Explicit trial uses the existing loader, and promotion assigns a default only after activation succeeds. Existing Root owns a strong reference to its selected Kernel instance and keeps using the same dispatcher and frozen policy across promotion and owner destruction.

Retirement reports the selected default, pinned admission and every outstanding physical ticket. Once quiet, existing ordered shutdown releases the generation. Late wake permits and retired-generation admission reject without effects. Real worker file descriptors return to baseline.
