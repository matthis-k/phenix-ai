# M0.2 implementation acceptance

The eleven canonical Nix gates pass locally, including independent pending roots, typed pending imports, lifecycle ordering, CLI products and descriptor retention. Subsequent generation and shipping gates revalidate this same mechanism. Exact-head CI and final realized outputs are recorded in PR #771.

`PendingImport<O>` is opaque, nonportable and cannot cross threads. Poll and cancel require a fresh PendingHost. Host scope or command rejection does not consume the handle or claim physical quiescence. A child binds its parent, root, caller, operation and frozen authority. Wakes request polling on the child and ancestor chain without retaining a Kernel address.

Logical failure or cancellation revokes effects before cleanup. Native completion while an imported child remains live fails the protocol and retains the parent image. A native-quiescent parent is never polled again; the kernel drains its children through revoked scopes. Imported results transfer once, after physical quiescence. Root abandonment owns and drains the entire tree.

SDK-only pending-consumer and pending-immediate fixtures prove typed completion, domain and kernel errors, immediate provider selection, ancestor wakes, attenuation, denial before worker acquisition, wrong-parent rejection without handle consumption, double settlement, invalid live-child completion, recursive cancellation and actual file descriptor release. Existing pending-root tests prove panic recovery, delayed callbacks, noncooperative leases and retained images on Kernel drop. Ordered lifecycle and real CLI checks also pass.

M0.3 reuses these leases and admission pins to control generation retirement. The supported profile remains trusted native code on x86_64 Linux.
